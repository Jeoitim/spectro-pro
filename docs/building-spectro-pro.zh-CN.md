# Building Spectro Pro：从一堂音乐通识课开始

[返回中文 README](../README.md) | [作者原文：Building Spectro](making-of.md) | [原文中文译本](making-of.zh-CN.md)

## 最早只是觉得它很有趣

我第一次接触 Spectro，是在一堂音乐通识课上。老师讲乐音和噪音的区别时，打开这个
项目，把声音直接变成了屏幕上的频率纹理。那一刻很直观：原本只能听见的东西，忽然
有了形状。

这件事正好碰到了我的兴趣。本科期间，我一直在和老师做语音、声学相关的研究，对语谱
图、基频、共振峰这些概念并不陌生。看到 Spectro 后，我很自然地冒出一个想法：如果它
不只显示频谱，还能在说话时实时给出各种语音参数，会不会更酷？

![原始 Spectro 界面](screenshot.png)

*原始 Spectro 已经把 Web Audio、后台 FFT 和 WebGL 绘制组合成了一个轻快的实时语谱图工具。*

## 从“看见声音”到“观察语音”

于是我 fork 了 Spectro，开始尝试改造它。最初并没有一份完整的功能清单，也没有想过
要把它做成另一个专业语音分析软件。我只是沿着最开始的问题继续往下走：语谱图之外，
还能不能看到波形？能不能把 F0 画出来？共振峰和音强是否也能在浏览器里实时计算？

原项目的结构给了我很好的起点。音频由 Web Audio 获取，FFT 放在 Worker 中计算，
WebGL 负责把不断到来的频谱列画到屏幕上。真正开始动手后，工作逐渐从“加几条曲线”
变成了对整条分析链路的重新梳理：窗口应该多长，宽带和窄带怎样取舍，算法在不同采样率
下是否稳定，离线音频和麦克风实时输入能否得到一致的结果，关闭某条轨迹时又该如何省下
对应的计算。

有些问题没有视觉效果那么显眼，却决定了这个工具是否可信。浏览器麦克风给出的采样没有
统一的物理校准，因此 dB SPL 必须明确标注它的使用边界；实时共振峰需要居中窗口，因此
画面要保留很短的分析延迟；F0 也不能只在一段干净的正弦波上工作，还要面对缺失基频、
高频干扰和无声片段。功能越多，我越觉得算法和限制都应该写清楚，而不是只留下几个看起
来很专业的数字。

## Praat 是参照，不是要被替代的对象

做语音和声学分析，很难绕开 Praat。它对语谱图窗长、Pitch、Burg LPC 共振峰和音强
计算的说明非常完整，也给了我核对实现的基础。Spectro Pro 的一些参数和公式参考了
Praat 官方文档，测试中也使用 Praat 6.6.30 生成的确定性参考帧来检查共振峰结果。

![Praat 中的波形、语谱图与语音标注](https://upload.wikimedia.org/wikipedia/commons/6/69/Waveform_spectrogram_and_transcription_of_wikipedia_in_praat.png)

*Praat 中的波形、语谱图与语音标注。图：Wugapodes，来源 [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Waveform_spectrogram_and_transcription_of_wikipedia_in_praat.png)；组件许可信息见原页面。*

但我从一开始就没有打算用一个浏览器工具替代 Praat，也不推荐把 Spectro Pro 直接用于
论文、临床或其他专业测量。专业工具之所以可靠，不只因为算法，还因为成熟的工作流、
可复现设置、设备校准和长期验证。Spectro Pro 更适合做另一件事：让这些平时有些抽象的
声学信息，随时可以被看见。

在课堂上演示宽带与窄带语谱的区别，打开麦克风观察自己说话时 F0 和共振峰的变化，或者
临时检查一台录音设备有没有削波、底噪是否异常，这些场景不需要先搭建复杂环境。只要有
现代浏览器，就能立即开始。我觉得这就是它的价值。

最后做出来的成品质量让我很欣喜。它当然还有边界，但合成信号测试和 Praat 参考帧表明，
目前的数据可靠程度已经相当不错。更重要的是，原先脑海里那个“如果能实时看到语音参数
就好了”的念头，确实变成了一个可以使用、可以解释、也可以继续修改的作品。

这次改造也让我重新体会到开源项目很迷人的一点：一个人在若干年前写下的 WebGL 语谱图，
会在另一间教室里被老师打开，又让一个原本研究语音和声学的学生产生新的想法。现在，
这些改动也继续以 MIT License 开放。

如果你发现算法、交互或文档中还有可以改进的地方，欢迎提出建议；也欢迎像我当初那样
fork 项目，按自己的用途自由改造。

**保持好奇，持续构建，让想法逐渐成为作品。**
